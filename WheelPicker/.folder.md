# Folder: WheelPicker

> Trigger: When this folder's structure/responsibilities/file list changes, update this document.
> 触发条件:当本文件夹的结构/职责/文件列表变化时,更新此文档。

This folder contains the app scene, the immersive demo screen, and the package-consumer shell. / 本目录包含应用场景、沉浸式示例界面，以及包消费者外壳。  
It consumes `WheelPickerKit` from the local Swift package and presents the package default picker as a black-backed arc composition with explicit initial-selection API wiring. / 它消费本地 Swift Package 中的 `WheelPickerKit`，并通过包默认选择器样式和公开的初始值 API 将选择器展示为黑底圆弧构图。
The invariant is that app-facing composition stays here, while shipped picker behavior, default styling, and default-value repair live under `Sources/`. / 最重要的不变量是应用侧界面构图留在这里，而分发的选择器行为、默认样式与默认值修正逻辑位于 `Sources/`。

## Files
- `ContentView.swift`: screen - Full-screen black-backed immersive arc demo composition using the package default style and explicit initial value wiring / 使用包默认样式与显式初始值接线的全屏黑底沉浸式圆弧示例组合
- `WheelPickerApp.swift`: app root - Application entry scene / 应用入口场景
- `WheelPicker.entitlements`: config - App sandbox entitlements / 应用沙盒权限配置
- `Assets.xcassets/`: child folder - App icons and color assets / 应用图标与颜色资源
- `.folder.md`: local map - Folder responsibilities and file list / 目录职责与文件列表
