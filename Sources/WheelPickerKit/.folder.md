# Folder: Sources/WheelPickerKit

> Trigger: When this folder's structure/responsibilities/file list changes, update this document.
> 触发条件:当本文件夹的结构/职责/文件列表变化时,更新此文档。

This folder contains the shipped picker module and no demo-only chrome. / 本目录只包含对外分发的选择器模块，不包含任何示例专用装饰层。
It exports `TimerWheelPicker` with yellow-major immersive-by-default behavior, mirrored shallow-arc swipe semantics, readable style aliases, explicit initial-selection fallback, tiered tick styling, tick-synced shallow arc strokes, typography colors, viewport fade timing, and value-position knobs while keeping geometry and feedback package-private. / 它导出默认黄色长刻度沉浸式行为、浅弧镜像滑动语义、易读样式别名、显式初始值回退、分级刻度样式、与刻度同步的浅弧线层、排版颜色、视口褪色时机与数字位置参数的 `TimerWheelPicker`，同时将几何与反馈保持为包内私有实现。
The invariant is that consumers configure arc skins, tick tiers, labels, and first-load defaults through explicit APIs instead of importing app-layer layout. / 最重要的不变量是使用者只能通过显式 API 配置圆弧皮肤、刻度层级、标签和首次加载默认值，而不是引入应用层布局。

## Files
- `TimerWheelPicker.swift`: public component - Public picker API, yellow-major immersive default behavior, initial-selection fallback, arc profiles, tick-fade timing/value-position knobs, tiered tick colors, typography colors, readable customization aliases, and reusable style presets / 公开选择器 API、默认黄色长刻度沉浸式行为、初始值回退、圆弧轮廓、刻度褪色时机与数字位置参数、分级刻度颜色、排版颜色、易读定制别名与可复用样式预设
- `WheelPickerView.swift`: package-private view - Shared full-bleed arc geometry, mirrored shallow-arc ordering, three-tier tick resolution, tick-synced shallow foreground/background arc rendering, viewport-driven fade timing, hit-region tuning, and arc-inside label placement / 共享贴边圆弧几何、浅弧镜像排序、三档刻度解析、与刻度同步的浅弧前景/背景线层渲染、视口驱动的褪色时机、命中区调优与圆弧内标签定位
- `WheelHapticController.swift`: package-private service - Dedicated rigid-impact plus low-latency metallic ratchet engine for per-tick wheel motion / 用于逐刻度滚轮运动的专用刚性冲击加低延迟金属棘轮引擎
